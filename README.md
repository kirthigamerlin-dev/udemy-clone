Udemy Clone
A simple HTML & CSS layout that replicates the look and feel of Udemy’s course listing interface. This project is built for practice and learning purposes, focusing on responsive design and clean structure.

📌 Features
Course listing layout similar to Udemy

Responsive design for desktop and mobile

Clean and reusable HTML structure

Styled with CSS for modern UI look
